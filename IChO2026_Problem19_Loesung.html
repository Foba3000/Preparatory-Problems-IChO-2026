🍬 Problem 19 – Kohlenhydrate als chirale Ausgangsstoffe
Vollständige Lösung – L-Sorbose, Thromboxan B2 & Swainsonin aus chiralen Zuckern

📚 Grundprinzip: Der chirale Pool

Der chirale Pool bezeichnet den Vorrat an enantiomerenreinen Naturstoffen (Zucker, Aminosäuren, Terpene), die als Ausgangsstoffe für die Synthese chiraler Wirkstoffe dienen. Kohlenhydrate sind besonders wertvoll, da sie:
  • Günstig und im Großmaßstab verfügbar sind
  • Mehrere definierte Stereozentren besitzen
  • Ihre Stereochemie selektiv modifiziert werden kann (Oxidation/Reduktion, SN2-Inversion)
  • Als Bausteine für komplexe Naturstoffe (Alkaloide, Prostanoide) geeignet sind

Teil 1: L-Sorbose → Pyrrolidinol-Alkaloid X

Aufgaben 1 & 2: Synthese von X aus L-Sorbose-Derivat A

Ausgangsstoff A: L-Sorbose-Derivat mit Dioxolan-Schutzgruppe (cyclisches Acetal), Tosylat (TsO⁻) als Abgangsgruppe und Acetat-Schutzgruppen (OAc).

Reaktionssequenz A → X

1 A + LiN₃ → B (Azidierung)
LiN₃ = Lithiumazid
  • TsO⁻ ist eine exzellente Abgangsgruppe (Tosylat)
  • N₃⁻ (Azid-Ion) als Nukleophil: SN2-Angriff → Inversion der Konfiguration am betreffenden C-Atom
  • Alle OAc-Gruppen bleiben erhalten
B = Azido-Zuckerderivat (N₃ statt TsO⁻, OAc-Gruppen intact)
2 B + 1) NaOMe, 2) H₃O⁺ → C (Entacetylierung)
  • NaOMe = Natriummethanolat (milde Base): Zemplén-Deacetylierung aller OAc → OH
  • Azid-Gruppe N₃ bleibt stabil gegenüber Base
  • H₃O⁺: saure Aufarbeitung, neutralisiert NaOMe
C = Azido-Polyol (alle OH-Gruppen frei, N₃-Gruppe erhalten)
3 C + H₂, Pd/C → X (Reduktion + intramolekulare Cyclisierung)
  • H₂/Pd/C: Reduktion N₃ → NH₂ (Amin entsteht in situ)
  • Das frisch gebildete NH₂ reagiert sofort mit der benachbarten Carbonyl-Gruppe: intramolekulare reduktive Aminierung
  • → Bildung eines 5-gliedrigen Pyrrolidin-Rings
X = C₆H₁₃NO₄ = Pyrrolidinol-Derivat (2,5-Dihydroxymethyl-pyrrolidin)
X = (2R,3R,4S)-2-(Hydroxymethyl)-3,4-dihydroxypyrrolidin

      HOCH₂           CH₂OH
        \             /
         C──────────C
        /│          │\
     HO │          │ OH
         C──────────C
          \        /
            N
            H

5-gliedriger Pyrrolidinring mit 2 CH₂OH-Gruppen und 2 OH-Gruppen
A = L-Sorbose-Derivat (mit Dioxolan, TsO⁻, OAc)
B = N₃-Zuckerderivat (SN2-Inversion, OAc erhalten)
C = N₃-Polyol (nach Zemplén-Deacetylierung)
X = 2,5-Dihydroxymethyl-3,4-dihydroxypyrrolidin (DMDP-Analogon)
Schlüsselschritt: H₂/Pd/C reduziert N₃ → NH₂, das spontan cyclisiert!

Teil 2: D-Glucose → Thromboxan B₂ (TxB₂)

Aufgaben 3 & 4: Synthese von Intermediat I und Reagenzienreihenfolge Z1–Z4

Thromboxan B₂ (TxB₂) ist ein biologisch aktives Eicosanoid (C20-Prostanoid) mit einem charakteristischen Tetrahydropyranyl-Ring, einer Alkohol-Seitenkette (C8–OH) und einer Carbonsäure-Kette. Die D-Glucose liefert den Tetrahydropyranyl-Baustein mit korrekter Stereochemie.

Synthese von D-Glucose → I

Formel: C₂₅H₃₂SiO₅ (laut Aufgabe)

Reagenzienreihenfolge Z1–Z4 für I → TxB₂

Ziel: Aus I müssen eingeführt werden: die Keton-Seitenkette (C(O)-(CH₂)₄-CH₃), die Carbonsäure-Seitenkette (COOH), freie OH-Gruppen → TxB₂
Analyse der vier Reagenz-Sätze:
  • Z1: 1) PCC, 2) Ph₃P=CH–C(O)(CH₂)₄CH₃ → Oxidation OH→Aldehyd, dann Wittig → Keton-Seitenkette
  • Z2: 1) BzCl, 2) Bu₄NF → OH schützen als OBz, dann OTBDPS entfernen (TBAF)
  • Z3: 1) NaBH₄, 2) K₂CO₃, 3) HCl → Keton/Aldehyd → OH, Verseifung OBz→OH, saure Entschützung
  • Z4: 1) DIBAL-H, 2) Ph₃P=CH(CH₂)₃COOH, 3) CH₂N₂ → Ester→Aldehyd, Wittig→Alken-COOH, CH₂N₂ schützt COOH als COOMe
Logische Reihenfolge:
  1. Z2 zuerst: BzCl schützt neu zugängliche OH (nach TBDPS-Entfernung würde C6-OH frei → schützen). Bu₄NF entfernt OTBDPS → C6-OH frei für nächste Reaktion
  2. Z1: PCC oxidiert das freie primäre C6-OH zum Aldehyd. Wittig-Reaktion führt die Keton-Seitenkette (Thromban-Kette) ein
  3. Z4: DIBAL-H reduziert den COOMe-Ester selektiv zum Aldehyd (−78°C). Wittig-Reaktion mit dem Ylid (COOH-Kette). CH₂N₂ schützt COOH temporär als COOMe
  4. Z3 zuletzt: NaBH₄ reduziert Keton → OH (stereoselektiv). K₂CO₃ verseift OBz → OH. HCl entfernt letzte Acetal-Schutzgruppen → TxB₂ fertig
Reihenfolge: Z2 → Z1 → Z4 → Z3

Teil 3: D-Mannose → (−)-Swainsonin

Aufgaben 5–7: Synthese von (−)-Swainsonin aus Benzyl-α-D-mannopyranosid

Swainsonin ist ein Indolizidinalkaloid (bicyclischer N-Heterocyclus: Pyrrolidin + Piperidin fusioniert) mit drei OH-Gruppen und starker biologischer Wirkung (Glycosidase-Inhibitor). D-Mannose liefert die vier benötigten Stereozentren.

Konfigurationen

Benzyl-α-D-mannopyranosid (Startmaterial)
  • C1: R (anomeres C, α-Konfiguration, axialer OBn)
  • C2: R (OH axial, Mannose-spezifisch – Epimerismus an C2 vs. Glucose)
  • C3: S
  • C4: R
  • C5: R

5 Stereozentren gesamt

(−)-Swainsonin (Produkt)
  • C1: S
  • C2: R
  • C3: R
  • C8a: S (N-Brückenposition)

4 Stereozentren im bicyclischen System

3 der Mannose-Stereozentren werden direkt übernommen!

Aufgabe 7: Erhaltene vs. neu gesetzte Stereozentren

Analyse der Stereochemie-Übertragung:
  • Aus D-Mannose DIREKT übernommen (unverändert): C2 und C3 (beide werden durch den Orthoformiat-Schutz nicht angegriffen; ihre relative Konfiguration bleibt exakt erhalten)
  • C4 (Mannose) → C4 in Swainsonin: Doppelte Inversion (Oxidation/Reduktion + Triflat/Azid-SN2) → Netto-Retention der ursprünglichen Mannose-Konfiguration an dieser Position!
  • C5 (Mannose): Bleibt im Ring, Konfiguration übernommen
  • NEU gesetzt: C8a (das N-Brücken-C beim Ringschluss) – dieses Stereozentrum entsteht beim intramolekularen Iminiumion-Angriff (durch thermodynamische Kontrolle bevorzugt)
Eleganz der Synthesestrategie:
Die Mannose-Stereochemie wird direkt auf das Alkaloid übertragen. Durch gezielten Einsatz von Oxidation/Reduktion und SN2-Reaktionen mit Inversion kann die natürliche Konfiguration der Mannose selektiv modifiziert werden, um die gewünschte Swainsonin-Stereochemie zu erhalten – ohne aufwändige asymmetrische Katalyse!
Erhaltene Stereozentren aus D-Mannose: C2, C3, C5 (Konfiguration direkt übernommen)
Modifiziert durch doppelte Inversion: C4 (Netto-Retention)
Neu eingeführt: C8a (durch intramolekulare Cyclisierung)

→ (−)-Swainsonin: (1S,2R,3R,8aS)-1,2,3-Trihydroxyindolizidin

Gemeinsames Designprinzip aller drei Syntheserouten:
Die Stereochemie des Zuckers wird gezielt genutzt: (1) Direkte Übertragung erhaltener Zentren, (2) Kontrollierte Inversion durch SN2-Reaktionen, (3) Diastereoselektive Reduktionen nutzen die vorhandene Chiralität als dirigierende Gruppe. Kein aufwändiger chiraler Katalysator ist nötig!
