🔬 Problem 26 – Sensing of Acetaldehyde
Vollständige Lösung auf Deutsch – Reaktionsmechanismus, Kinetik & Spektroskopie

📚 Überblick: Worum geht es?

Acetaldehyd (AA, CH₃CHO) entsteht als Zwischenprodukt beim Ethanolabbau in Zellen und ist in hohen Konzentrationen toxisch. Die Verbindung AAP-1 erkennt AA hochselektiv durch eine zweistufige Reaktion: zuerst bildet sich ein Enamin (A), das dann über eine [4+2]-Cycloaddition (Diels-Alder) mit einer Tetrazin-Einheit in AAP-1 reagiert, gefolgt von einer Retro-[4+2]-Cycloaddition unter Freisetzung von N₂ – der entstandene fluoreszente Analyt P ermöglicht die Detektion.

Zentrale Themen: Enamin-Bildung · Inverse Electron Demand Diels-Alder (IEDDA) · Tetrazin-Chemie · Selektivität · Gibbs-Energie · Eyring/Arrhenius · Fluoreszenzspektroskopie · Michaelis-Menten-Kinetik

Aufgabe 1: Strukturen A–B, Produkt P und anorganisches Nebenprodukt C

Schlüsselprinzip: Tetrazin-IEDDA (Inverse Electron Demand Diels-Alder)

AAP-1 enthält zwei reaktive Gruppen:
  • Ein sekundäres Amin (Pyrrolidin, N–H) → reagiert mit AA zu einem Enamin (A)
  • Eine 1,2,4,5-Tetrazin-Einheit (4π-Dien, LUMO-dominiert) → reagiert in der IEDDA mit dem Enamin-Dienophil
Nach dem Mechanismus AAP-1 + AA → A + H₂O → B → P + C (N₂)

Massenbilanzkontrolle

M(AAP-1) + M(AA) − M(H₂O) − M(N₂) = M(P)
494 + 44 − 18 − 28 = 492 ✓
Damit sind: A (520), B (520), P (492), C = N₂ (28) vollständig konsistent.

Schritt 1: Bildung von A (Enamin) aus AAP-1 + AA − H₂O

1 Das sekundäre Amin des Pyrrolidin-Rings in AAP-1 (N–H) reagiert mit Acetaldehyd (CH₃CHO):
Pyrrolidin-NH + CH₃CHO → Hemiaminal → Iminium R₂N⁺=CH–CH₃ → –H⁺ → Enamin A
A = Enamin: Die N–H-Gruppe ist durch –N–CH=CH₂ ersetzt worden. Der N gibt seine Elektronen in das π-System; die Doppelbindung liegt zwischen den β- und γ-Kohlenstoffen (CH=CH₂). A ist elektronenreich (N-Donator) → gutes Dienophil für die IEDDA. M(A) = 494 + 44 − 18 = 520.

Schritt 2: [4+2]-Cycloaddition → B (intramolekular)

2 Das Enamin (2π-Dienophil, HOMO-reich) reagiert intramolekular mit der 1,2,4,5-Tetrazin-Einheit (4π-Dien, LUMO-arm = inverse Elektronenbedarfs-DA):
Tetrazin (Dien, 4π) + Enamin CH₂=CH–NR₂ (Dienophil, 2π) → bicyclischer Addukt B
Die Tetrazin-N=N–C=N–N=C-Einheit dient als heterocyclisches Dien. B = bicyclisches Zwischenprodukt (Diaza-Bicyclo[2.2.2]-Typ mit N–N-Brücke). M(B) = 520 (gleich wie A, keine Massenänderung bei Cyclisierung).

Schritt 3: Retro-[4+2] → P + C

3 Das bicyclische Zwischenprodukt B unterliegt der spontanen Retro-Diels-Alder-Reaktion: Die N–N-Brücke des Bicyclus bricht, und N₂ (Diickstoff) wird freigesetzt.
B (bicyclisch) → P (Dihydropyridazin-Produkt) + N₂
P: Das Tetrazin-Ring-System ist in ein 1,2-Dihydropyridazin-System (6-Ring mit zwei benachbarten N-Atomen) umgewandelt worden. P hat gleich viele Ringe wie AAP-1, da das alte Tetrazin (1 Ring) durch das neue Dihydropyridazin (1 Ring) ersetzt wird. P ist stark fluoreszent, da die tetrazin-vermittelte Fluoreszenzlöschung entfällt. M(P) = 492.

Zusammenfassung Aufgabe 1:
• A (M = 520): Enamin; AAP-1 mit N–CH=CH₂ statt N–H (Pyrrolidin + AA, –H₂O)
• B (M = 520): Bicyclischer [4+2]-Addukt aus intramolekularer IEDDA (Enamin = Dienophil, Tetrazin = Dien)
• C = N₂ (Distickstoff, M = 28): Anorganisches Nebenprodukt der Retro-[4+2]-Reaktion
• P (M = 492): Fluoreszentes Dihydropyridazin-Produkt; enthält gleich viele Ringe wie AAP-1

Aufgabe 2: Warum reagieren Formaldehyd und Methylglyoxal nicht mit AAP-1?

Voraussetzung für die Reaktion: Enamin-Bildung

Der erste Schritt ist die Bildung eines Enamins an der Pyrrolidin-N–H-Gruppe. Dafür wird benötigt: ein Iminium-Ion, das anschließend ein α-H am α-Kohlenstoff (neben dem Iminium-C) verlieren kann. Nur dann bildet sich die C=C-Doppelbindung des Enamins.

Formaldehyd (Methanal, HCHO)

Reaktion mit dem Pyrrolidin-N–H:
R₂NH + H–CHO → R₂N–CH₂–OH → R₂N⁺=CH₂ (Iminium-Ion)
R₂N⁺=CH₂ → kein α-H verfügbar!
Das Iminium R₂N⁺=CH₂ besitzt keinen α-Kohlenstoff, von dem ein H⁺ abstrahiert werden könnte, um die C=C-Doppelbindung zu bilden. Formaldehyd hat kein Kohlenstoff- Rückgrat hinter dem Carbonyl → kein Enamin bildbar → keine Reaktion.

Methylglyoxal (2-Oxopropanal, CH₃–CO–CHO)

Versuch über die Aldehyd-Gruppe:
R₂NH + CHO–CO–CH₃ → R₂N⁺=CH–CO–CH₃ (Iminium)
α-Kohlenstoff zum Iminium-C = der Keton-Carbonyl-C (C=O, kein H!)
Der α-Kohlenstoff neben dem Iminium-Kohlenstoff ist das Carbonyl-C des Ketons, das kein H trägt → keine Enamin-Bildung über den Aldehyd möglich.

Versuch über die Keton-Gruppe:
R₂NH + CH₃–CO–CHO → R₂N⁺=C(CH₃)–CHO (Iminium vom Keton) → Enamin: R₂N–C(CHO)=CH₂
Das gebildete Enamin ist elektronenarm (EWG = –CHO am Vinylkohlenstoff)
Das entstehende Enamin wäre durch die benachbarte CHO-Gruppe elektron-verarmt (niedrige HOMO-Energie). Es ist damit ein schlechtes Dienophil für die IEDDA mit dem ebenfalls elektronenarmen Tetrazin (LUMO-dominiert). Die Energiedifferenz zwischen LUMO(Tetrazin) und HOMO(Enamin) wäre zu groß → keine IEDDA → keine Reaktion.
Formaldehyd: Kein α-H vorhanden → kein Enamin bildbar
Methylglyoxal: Via Aldehyd: α-C ist ein Carbonyl-C (kein H). Via Keton: das gebildete Enamin ist durch die CHO-Gruppe elektronenarm und daher als HOMO-armes Dienophil für die IEDDA mit dem elektronenarmen Tetrazin ungeeignet.

Aufgabe 3: Gibbs-Energieänderungen für A→B und A'→B'

Die Reaktions-Gibbs-Energie ΔG ergibt sich als Differenz der relativen Gibbs-Energien von Produkt und Edukt. Alle Werte sind auf die Ausgangsmaterialien (Reagenzien) bezogen.

Reaktion A → B (Acetaldehyd-System)

ΔG(A→B) = ΔG(B) − ΔG(A) = (−21,74) − (−8,36) = −21,74 + 8,36 = −13,38 kJ·mol⁻¹
ΔG < 0 → die Reaktion A→B ist spontan

Reaktion A' → B' (Hexanal-System)

ΔG(A'→B') = ΔG(B') − ΔG(A') = (−19,23) − (−12,96) = −19,23 + 12,96 = −6,27 kJ·mol⁻¹
ΔG < 0 → die Reaktion A'→B' ist ebenfalls spontan, jedoch weniger stark getrieben als A→B.
Hinweis: Obwohl A'→B' weniger exergon ist und eine höhere Aktivierungsbarriere aufweist (stärkere sterische Hinderung durch die Hexyl-Kette), bleibt die Reaktion thermodynamisch erlaubt. Die Selektivität von AAP-1 gegenüber größeren Aldehyden beruht daher auf kinetischen, nicht thermodynamischen Gründen.

Aufgabe 4: Verhältnis der Geschwindigkeitskonstanten k(A→B) / k(A'→B') bei T = 310 K

1 Aktivierungsenergien berechnen (= ΔG‡ = Aktivierungs-Gibbs-Energie):
Ea₁ = ΔG‡(A→B) = ΔG(TS₁) − ΔG(A) = 63,95 − (−8,36) = 72,31 kJ·mol⁻¹
Ea₂ = ΔG‡(A'→B') = ΔG(TS₂) − ΔG(A') = 68,13 − (−12,96) = 81,09 kJ·mol⁻¹
2 Arrhenius-Gleichung mit gleichem Präexponentialfaktor A:
k₁ = A · e^(−Ea₁/RT)      k₂ = A · e^(−Ea₂/RT)
k₁/k₂ = exp[(Ea₂ − Ea₁) / (RT)] = exp[(81,09 − 72,31) · 1000 / (8,314 · 310)]
3 Numerische Auswertung:
ΔEa = Ea₂ − Ea₁ = 8,78 kJ·mol⁻¹ = 8780 J·mol⁻¹
RT = 8,314 J·mol⁻¹·K⁻¹ × 310 K = 2577,3 J·mol⁻¹
k₁/k₂ = exp(8780 / 2577,3) = exp(3,408) ≈ 30,2
k(A→B) / k(A'→B') ≈ 30

Die Cycloaddition mit dem Acetaldehyd-Enamin (A) läuft ca. 30× schneller ab als mit dem Hexanal-Enamin (A'). Der Grund: die größere sterische Hinderung der Hexyl-Kette erhöht die Aktivierungsenergie um ~8,78 kJ/mol. Dies erklärt, warum AAP-1 selektiv für kleine Aldehyde ist – größere Moleküle reagieren kinetisch zu langsam.

Aufgabe 5: Zuordnung der Spektrallinien X und Y zu Anregungs- und Emissionsprozessen

In der Fluoreszenzspektroskopie gilt das Stokes'sche Verschiebungsgesetz: Das emittierte Licht hat immer eine größere Wellenlänge (geringere Energie) als das absorbierende/anregende Licht, da ein Teil der Energie als Wärme (Schwingungsrelaxation) abgegeben wird.

Aus dem Spektrum:
  • X zeigt ein Maximum bei kürzerer Wellenlänge (~430 nm) → entspricht der Absorption von hochenergetischem Licht
  • Y zeigt ein Maximum bei längerer Wellenlänge (~530 nm) → entspricht der Emission von niederenergetischem Licht
X = Anregungsspektrum (Excitation) – misst bei welchen Wellenlängen Licht absorbiert wird → kürzere Wellenlängen (höhere Energie)
Y = Emissionsspektrum (Emission) – gibt das bei welchen Wellenlängen emittiert wird → längere Wellenlängen (niedrigere Energie, Stokes-Verschiebung)

Aufgabe 6: Berechnung von F₀ und k

Gegebene lineare Abhängigkeit: F = F₀ + k·[P]

1 Steigung k bestimmen aus den Differenzen:
Δ[P] = 10 μM → ΔF = 5,00 arb.u. (konstant bei allen Datenpunkten)
k = ΔF / Δ[P] = 5,00 / 10 = 0,50 arb.u.·μM⁻¹
2 F₀ berechnen (Einsetzen eines beliebigen Datenpunkts):

Aufgabe 7: Zeitberechnung für den Fluoreszenzabfall (Michaelis-Menten-Kinetik)

Schritt 1: Konzentration von AA aus der Fluoreszenz ableiten

Die Fluoreszenz spiegelt die aktuelle [AA]-Konzentration wider ([P] ∝ [AA]).
[AA] = (F − F₀) / k
Bei F = 137,50 arb.u.: [AA]₀ = (137,50 − 87,50) / 0,50 = 50,00 / 0,50 = 100 μM
Bei F = 90,65 arb.u.: [AA]f = (90,65 − 87,50) / 0,50 = 3,15 / 0,50 = 6,30 μM

Schritt 2: Integrierte Michaelis-Menten-Gleichung anwenden

Die Michaelis-Menten-Kinetik lautet: −d[AA]/dt = Vmax·[AA] / (KM + [AA])
Integration liefert:
t = (1 / Vmax) · { ([AA]₀ − [AA]f) + KM · ln([AA]₀ / [AA]f) }

Schritt 3: Einsetzen der Werte

Gegeben: Vmax = 4,1 mM·min⁻¹ = 4100 μM·min⁻¹, KM = 0,2 μM
t = (1 / 4100) · { (100 − 6,30) + 0,2 · ln(100 / 6,30) } [μM / (μM·min⁻¹)]
t = (1 / 4100) · { 93,70 + 0,2 · ln(15,87) }
t = (1 / 4100) · { 93,70 + 0,2 · 2,765 }
t = (1 / 4100) · { 93,70 + 0,553 }
t = (1 / 4100) · 94,25 min = 0,02299 min
t = 0,02299 × 60 s = ≈ 1,38 s
Interpretation: Da [AA]₀ = 100 μM ≫ KM = 0,2 μM, arbeitet ALDH fast die gesamte Reaktionszeit im Sättigungsbereich (v ≈ Vmax = 4100 μM/min). Dies entspricht einer nahezu nullten Reaktionsordnung: t ≈ Δ[AA]/Vmax = 93,70/4100 min ≈ 1,37 s. Der KM-Korrekturterm (0,553/4100 min ≈ 0,008 s) ist vernachlässigbar klein.
Die Fluoreszenz fällt von 137,50 auf 90,65 arb.u. in ca. t ≈ 1,38 Sekunden. Der Abbau durch ALDH ist also extrem schnell, da das Enzym unter Sättigungsbedingungen arbeitet.
