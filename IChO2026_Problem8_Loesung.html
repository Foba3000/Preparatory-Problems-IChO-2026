🔗 Problem 8 – Schritt für Schritt: Polykondensation
Vollständige Lösung auf Deutsch – Kinetik, Carothers-Gleichung & Mechanismen

📚 Grundwissen: Was ist Polykondensation?

Polykondensation ist ein Polymerisationsverfahren, bei dem Monomere schrittweise unter Abspaltung kleiner Moleküle (meist H₂O) miteinander reagieren. Im Gegensatz zur Kettenpolymerisation wächst jede Kette nur langsam und alle Kettenlängen koexistieren zu jedem Zeitpunkt.

n HO–A–OH + n HOOC–B–COOH → H[–O–A–O–CO–B–CO–]ₙOH + (2n−1) H₂O
Schlüsselkonzepte:
• DP (Degree of Polymerisation): mittlere Anzahl der Monomereinheiten pro Kette
• p (Umrechnungsgrad): Anteil der bereits reagierten funktionellen Gruppen
• C: aktuelle Konzentration freier funktioneller Gruppen  |  C₀: Anfangskonzentration
• Annahme: Reaktivität unabhängig von der Kettenlänge

Aufgabe 2: Vereinfachte Kinetik mit [OH] = [COOH] = C

Mit der Annahme gleicher Konzentrationen: r = k · C · C = k · C²

1 Wert von z:
−dC/dt = k · C^z  mit  z = x + y = 1 + 1 = 2
2 Integration der Differentialgleichung (Trennung der Variablen):
−dC/dt = k·C²  →  −dC/C² = k·dt
∫[C₀→C] −C⁻² dC = ∫[0→t] k dt
[1/C]C₀C = k·t
1/C − 1/C₀ = k·t
z = 2      und      1/C − 1/C₀ = k·t

Aufgabe 3: Herleitung der Carothers-Gleichung DP = f(p)

Definitionen: DP = C₀/C und p = (C₀ − C)/C₀

1 p umformen:
p = (C₀ − C)/C₀ = 1 − C/C₀ → C/C₀ = 1 − p → C₀/C = 1/(1−p)
2 Einsetzen in DP = C₀/C:
DP = C₀/C = 1/(1−p)
DP = 1/(1−p)    (Carothers-Gleichung)
Bei p=0: DP=1 (nur Monomere)  |  Bei p=0,5: DP=2  |  Bei p=0,99: DP=100  |  Bei p→1: DP→∞
Wichtige Erkenntnis: Um hohe Polymerisationsgrade zu erreichen, muss der Umsatz extrem hoch sein! Bei p=0,99 (99% Umsatz) erhält man erst DP=100. Das ist der Grund, warum Polykondensationsreaktionen besonders reine Monomere und vollständige Reaktion erfordern.

Aufgabe 4: DP als Funktion der Zeit: DP = f(t)

1 Aus der integrierten Kinetikgleichung:
1/C − 1/C₀ = k·t  →  1/C = 1/C₀ + k·t
2 Umformen mit DP = C₀/C → 1/C = DP/C₀:
DP/C₀ = 1/C₀ + k·t  →  DP = 1 + k·C₀·t
DP = 1 + k·C₀·t
DP wächst linear mit der Zeit! Die Steigung ist k·C₀.

Aufgabe 5: Lineare Beziehung zwischen p und t

Wir kombinieren DP = f(p) und DP = f(t):

1 Aus Carothers: DP = 1/(1−p)
Aus Kinetik: DP = 1 + k·C₀·t
2 Gleichsetzen:
1/(1−p) = 1 + k·C₀·t
3 Umformen (Linearform):
1/(1−p) − 1 = k·C₀·t
[1 − (1−p)] / (1−p) = k·C₀·t
p/(1−p) = k·C₀·t
p/(1−p) = k·C₀·t      bzw.      1/(1−p) = 1 + k·C₀·t
Trägt man 1/(1−p) gegen t auf, erhält man eine Gerade mit Steigung k·C₀ und Achsenabschnitt 1.

Aufgabe 6: Gleichgewichtskonstanten KF und KCl

🔵 DFDPS (ArF) – 3-Körper-Mechanismus

Erster Schritt: ArF + 2B ⇌ [ArF···2B]

Das Intermediat enthält ein ArF und zwei B-Einheiten.

KF = [ArF···2B] / ([ArF]·[B]²)

Einheit: M⁻² (da 3 Körper → 1 Körper)

🔴 DCDPS (ArCl) – 2-Körper-Mechanismus

Erster Schritt: ArCl + B ⇌ [ArCl···B]

Das Intermediat enthält ein ArCl und eine B-Einheit.

KCl = [ArCl···B] / ([ArCl]·[B])

Einheit: M⁻¹ (da 2 Körper → 1 Körper)

KF = [ArF···2B] / ([ArF]·[B]²)     KCl = [ArCl···B] / ([ArCl]·[B])

Aufgabe 7: Gesamtratengesetze für ArF und ArCl

Annahme: Das Vor-Gleichgewicht stellt sich sehr schnell ein, der zweite Schritt (Produktbildung) ist geschwindigkeitsbestimmend.

🔵 DFDPS (ArF) – 3. Ordnung
r = kF·[ArF···2B]
Mit KF·[ArF]·[B]² = [ArF···2B]:
r = kF·KF·[ArF]·[B]²
r = kobs,F·[ArF]¹·[B]²

mit kobs,F = kF·KF

Gesamtordnung: 3 (m=1, n=2)

🔴 DCDPS (ArCl) – 2. Ordnung
r = kCl·[ArCl···B]
Mit KCl·[ArCl]·[B] = [ArCl···B]:
r = kCl·KCl·[ArCl]·[B]
r = kobs,Cl·[ArCl]¹·[B]¹

mit kobs,Cl = kCl·KCl

Gesamtordnung: 2 (m=1, n=1)

Warum der Unterschied? F⁻ ist eine schlechtere Abgangsgruppe als Cl⁻ (F ist stärker gebunden), daher braucht ArF zwei Nukleophile (B) gleichzeitig im Übergangszustand, um die Reaktion zu ermöglichen. ArCl hingegen reagiert direkt mit einem B.

Aufgabe 8: DP = f(t) für DFDPS und Berechnung nach 1 Stunde

Für DFDPS gilt mit [ArF] = [B] = C: r = kobs·[ArF]·[B]² = kobs·C³

1 Differentialgleichung und Integration:
−dC/dt = kobs·C³
−C⁻³ dC = kobs·dt
∫[C₀→C] −C⁻³ dC = ∫[0→t] kobs dt
[1/(2C²)]C₀C = kobs·t
1/(2C²) − 1/(2C₀²) = kobs·t
1/C² − 1/C₀² = 2·kobs·t
2 Umschreiben mit DP = C₀/C → 1/C = DP/C₀:
DP²/C₀² − 1/C₀² = 2·kobs·t
(DP² − 1)/C₀² = 2·kobs·t
DP² = 1 + 2·kobs·C₀²·t
DP = √(1 + 2·kobs·C₀²·t)
DP wächst mit √t (langsamer als linear!) – im Gegensatz zu DP ~ t bei 2. Ordnung
3 Berechnung nach t = 1 h:
kobs = 7023 L²·mol⁻²·h⁻¹, C₀ = 0,1633 M
DP² = 1 + 2 × 7023 × (0,1633)² × 1
     = 1 + 2 × 7023 × 0,026667
     = 1 + 374,56
     = 375,56
DP = √375,56 = 19,4
DP nach 1 Stunde: DP ≈ 19

Das entspricht einem mittleren Polymerisationsgrad von 19 Monomereinheiten pro Kette nach nur 1 Stunde Reaktion.

Aufgabe 9: Qualitativer Graph DP = f(t) für ξ = 1 und ξ > 1

Wenn jeder Propagationsschritt um den Faktor ξ beschleunigt wird:

  • ξ = 1: Klassischer Fall – DP wächst linear mit t (DP = 1 + k·C₀·t)
  • ξ > 1: Jede neue Einheit macht die Kette reaktiver → DP wächst superlinear, divergiert bei einer kritischen Zeit tkrit
Qualitatives Verhalten:
• ξ = 1: Gerade (lineare Zunahme von DP mit t)
• ξ > 1: Konvexe Kurve (Krümmung nach oben), die bei t = tkrit gegen unendlich divergiert
• Bei t > tkrit: physikalisch: Gelatinierung / Phasenübergang (unlösliches Gel)

Aufgabe 10: Herleitung DP = f(t) für ξ > 1

Im beschleunigenden Modell gilt: Die Ratenkonstante für eine Kette der Länge n ist k_n = k·ξ^(n−1). Da DP der mittlere Polymerisationsgrad ist, gilt effektiv:

1 Modifizierte DGL:
−dC/dt = k·ξ^(DP−1)·C²
Mit DP = C₀/C einsetzen: DP−1 = C₀/C − 1
2 Substitution u = DP = C₀/C (C = C₀/u, dC = −C₀/u² du):
dC/dt = −C₀/u² · du/dt
Einsetzen in DGL:
C₀/u² · du/dt = k·ξ^(u−1) · C₀²/u²
du/dt = k·C₀·ξ^(u−1)
3 Trennung der Variablen:
du / ξ^(u−1) = k·C₀·dt
ξ^(1−u) du = k·C₀·dt
4 Integration (Anfangsbedingung: u=1 bei t=0):
∫[1→DP] ξ^(1−u) du = k·C₀·t

[−ξ^(1−u)/ln(ξ)]1DP = k·C₀·t

−ξ^(1−DP)/ln(ξ) + ξ^0/ln(ξ) = k·C₀·t

[1 − ξ^(1−DP)] / ln(ξ) = k·C₀·t
5 Auflösen nach DP:
1 − ξ^(1−DP) = k·C₀·t·ln(ξ)
ξ^(1−DP) = 1 − k·C₀·t·ln(ξ)
(1−DP)·ln(ξ) = ln(1 − k·C₀·t·ln(ξ))
1−DP = ln(1 − k·C₀·t·ln(ξ)) / ln(ξ)
DP = 1 − ln(1 − k·C₀·t·ln ξ) / ln ξ
6 Grenzfall ξ→1 (Überprüfung):
Für kleine ln(ξ) ≈ ξ−1 → 0: Taylor-Entwicklung ln(1−x) ≈ −x für kleines x:
DP ≈ 1 − (−k·C₀·t·ln(ξ))/ln(ξ) = 1 + k·C₀·t ✓
Das ergibt exakt den linearen Fall aus Aufgabe 4!
7 Kritische Zeit tkrit (DP → ∞):
1 − k·C₀·tkrit·ln(ξ) = 0 → tkrit = 1/(k·C₀·ln(ξ))
Bei t = tkrit divergiert DP → ∞: physikalisch bedeutet das Gelatinierung des Polymersystems.
Physikalische Bedeutung: Für ξ > 1 gibt es eine endliche kritische Zeit, nach der das mathematische Modell einen unendlich langen Polymerisationsgrad vorhersagt. In der Praxis bildet sich ein dreidimensionales vernetztes Netzwerk (Gel), das keine definierte Löslichkeit mehr besitzt. Dieser Gel-Punkt ist ein wichtiges Konzept in der Polymertechnologie.
DP(t, ξ>1) = 1 − ln(1 − k·C₀·t·ln ξ) / ln ξ

Grenzfall: ξ=1 → DP = 1 + k·C₀·t ✓
Kritische Zeit: tkrit = 1/(k·C₀·ln ξ) → DP → ∞ (Gelierung)
