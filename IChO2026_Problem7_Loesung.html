📚 Grundwissen: Was ist Urease?

Urease ist ein Enzym, das die Hydrolyse von Harnstoff (Urea) katalysiert:

CO(NH₂)₂ + H₂O → CO₂ + 2 NH₃

Das aktive Zentrum der Urease ist eine zweiprotonige Säure (H₂U) mit zwei pKₐ-Werten. Nur die einfach deprotonierte Form HU⁻ ist enzymatisch aktiv. Diese pH-Abhängigkeit ist der Schlüssel zu fast allen Berechnungen in dieser Aufgabe.

pKₐ-Werte des aktiven Zentrums:
H₂U ⇌ HU⁻ + H⁺  →  pKₐ₁ = 5,62  (Ka₁ = 2,40 × 10⁻⁶ M)
HU⁻ ⇌ U²⁻ + H⁺  →  pKₐ₂ = 9,07  (Ka₂ = 8,51 × 10⁻¹⁰ M)

Aufgabe 1: Michaelis-Menten-Herleitung mit pH-Abhängigkeit

Gesucht: v als Funktion von [U]total, [S]total und [H⁺].

Schritt 1: [HU⁻] aus [U]total ausdrücken

Die drei Urease-Formen stehen im Gleichgewicht:

Ka₁ = [HU⁻]·[H⁺]/[H₂U]  →  [H₂U] = [HU⁻]·[H⁺]/Ka₁
Ka₂ = [U²⁻]·[H⁺]/[HU⁻]  →  [U²⁻] = Ka₂·[HU⁻]/[H⁺]

[U]total = [H₂U] + [HU⁻] + [U²⁻]
            = [HU⁻]·[H⁺]/Ka₁ + [HU⁻] + Ka₂·[HU⁻]/[H⁺]
            = [HU⁻] · ( [H⁺]/Ka₁ + 1 + Ka₂/[H⁺] )
            = [HU⁻] · ( [H⁺]² + Ka₁·[H⁺] + Ka₁·Ka₂ ) / (Ka₁·[H⁺])
[HU⁻] = Ka₁·[H⁺]·[U]total / ([H⁺]² + Ka₁·[H⁺] + Ka₁·Ka₂)

Schritt 2: Steady-State-Näherung für den Enzym-Substrat-Komplex [ES]

Mechanismus: HU⁻ + S ⇌ [HU⁻·S] → HU⁻ + Produkte

Steady-State für [ES]: d[ES]/dt = 0
k₁·[HU⁻]·[S] − k₋₁·[ES] − k₂·[ES] = 0
[ES] = k₁·[HU⁻]·[S] / (k₋₁+k₂) = [HU⁻]·[S] / Km
mit Km = (k₋₁+k₂)/k₁
Da [S]total ≫ [U]total: [S] ≈ [S]total

Schritt 3: Reaktionsrate

v = k₂·[ES] = k₂·[HU⁻]·[S]total / (Km + [S]total)

Einsetzen von [HU⁻]:

Endformel (Aufgabe 1):
v = k₂ · Ka₁·[H⁺]·[U]total·[S]total / { ([H⁺]² + Ka₁·[H⁺] + Ka₁·Ka₂) · (Km + [S]total) }

Aufgabe 2: Reaktionsordnungen in Pufferlösung

In Pufferlösung ist [H⁺] konstant → der pH-abhängige Vorfaktor ist eine Konstante k_eff.

v = k_eff · [U]total · [S]total / (Km + [S]total)

Die Reaktionsordnung bezüglich Urease ist immer 1. Ordnung (linearer Faktor [U]total).

a) Wenn Km = (k₋₁+k₂)/k₁ ≫ [S]total:

Km + [S]total ≈ Km (konstant)
v ≈ (k_eff/Km) · [U]total · [S]total
Bezüglich Urease: 1. Ordnung
Bezüglich CO(NH₂)₂: 1. Ordnung
→ Gesamtreaktion 2. Ordnung (bimolekular)

b) Wenn Km ≪ [S]total:

Km + [S]total ≈ [S]total
v ≈ k_eff · [U]total
Bezüglich Urease: 1. Ordnung
Bezüglich CO(NH₂)₂: 0. Ordnung (Enzym ist gesättigt)
→ Maximale Reaktionsrate (vmax-Bereich der Michaelis-Menten-Kurve)

Aufgabe 3: pH bei maximaler Reaktionsrate

Die Rate ist proportional zu [HU⁻], was wiederum proportional zu:

f([H⁺]) = Ka₁·[H⁺] / ([H⁺]² + Ka₁·[H⁺] + Ka₁·Ka₂)

Wir maximieren f durch Differentiation nach [H⁺] und Nullsetzen:

1 Ableitung und Nullsetzen (Quotientenregel):
df/d[H⁺] = Ka₁·([H⁺]² + Ka₁·[H⁺] + Ka₁·Ka₂) − Ka₁·[H⁺]·(2·[H⁺] + Ka₁) = 0

Vereinfachen (Ka₁ kürzen):
[H⁺]² + Ka₁·[H⁺] + Ka₁·Ka₂ − 2·[H⁺]² − Ka₁·[H⁺] = 0
−[H⁺]² + Ka₁·Ka₂ = 0
[H⁺]² = Ka₁·Ka₂
2 Logarithmieren:
−2·pH = −pKa₁ − pKa₂ → pHopt = (pKa₁ + pKa₂) / 2
3 Einsetzen:
pHopt = (5,62 + 9,07) / 2 = 7,35
pH der maximalen Urease-Aktivität: pH = 7,35

Das ist nahezu neutral – das passt gut zur biologischen Rolle der Urease im Boden und in Organismen (physiologischer pH ~7,4).
pH →
        ▲ Rate
       ╭───╮
      ╭╯   ╰╮
     ╭╯     ╰╮
─────┴──────────────┴─── pH
   5,62   7,35   9,07
  pKa₁   max    pKa₂

Aufgabe 4a: pH nach Zersetzung von 0,005 M Harnstoff

Reaktion: CO(NH₂)₂ + H₂O → CO₂ + 2 NH₃

Aus 0,005 M Harnstoff entstehen: 0,010 M NH₃ + 0,005 M CO₂(aq)

1 Welche Form liegt bei welchem pH vor?
• NH₃/NH₄⁺: pKₐ(NH₄⁺) = 14 − 4,75 = 9,25
• CO₂/HCO₃⁻: pKₐ₁ = 3,75 → bei pH ≫ 3,75 liegt fast alles als HCO₃⁻ vor
• HCO₃⁻/CO₃²⁻: pKₐ₂ = 10,33 → bei pH ≪ 10,33 liegt fast alles als HCO₃⁻ vor
2 Schätzung des pH: Wir erwarten pH ≈ 9 (zwischen pKₐ(NH₄⁺)=9,25 und weit über pKₐ₁=3,75). Bei pH ~9 gilt:
→ CO₂ liegt praktisch vollständig als HCO₃⁻ vor: [HCO₃⁻] ≈ 0,005 M
3 Ladungsbilanz (vereinfacht, CO₃²⁻ vernachlässigbar bei pH < 10,33):
[NH₄⁺] + [H⁺] ≈ [HCO₃⁻] + [OH⁻]
Bei pH ≈ 9: [H⁺] ≈ [OH⁻] ≈ 10⁻⁵ M (vernachlässigbar gegenüber 0,005 M) → [NH₄⁺] ≈ [HCO₃⁻] = 0,005 M
4 Henderson-Hasselbalch für NH₃/NH₄⁺:
[NH₃] + [NH₄⁺] = 0,010 M und [NH₄⁺] = 0,005 M → [NH₃] = 0,005 M
pH = pKₐ(NH₄⁺) + log([NH₃]/[NH₄⁺]) = 9,25 + log(0,005/0,005) = 9,25 + 0 = 9,25
pH nach vollständiger Harnstoff-Zersetzung = 9,25

Dies liegt deutlich über dem pH-Optimum der Urease (7,35) – die Reaktion verlangsamt sich also durch ihre eigenen Produkte selbst!

Aufgabe 4b: Faktor der Aktivitätsabnahme (pH 7 → pH 9,25)

Die Rate ist proportional zu [HU⁻]/[U]total = f([H⁺]). Der Faktor der Abnahme ist das Verhältnis f bei pH=7 zu f bei pH=9,25.

f([H⁺]) = Ka₁·[H⁺] / ([H⁺]² + Ka₁·[H⁺] + Ka₁·Ka₂)
1 Bei pH = 7,00: [H⁺] = 10⁻⁷ M
Zähler: Ka₁·[H⁺] = 2,40×10⁻⁶ × 10⁻⁷ = 2,40×10⁻¹³
Nenner: (10⁻⁷)² + 2,40×10⁻⁶·10⁻⁷ + 2,40×10⁻⁶·8,51×10⁻¹⁰
       = 10⁻¹⁴ + 2,40×10⁻¹³ + 2,04×10⁻¹⁵ = 2,52×10⁻¹³
f(pH=7) = 2,40×10⁻¹³ / 2,52×10⁻¹³ = 0,952
2 Bei pH = 9,25: [H⁺] = 5,62×10⁻¹⁰ M
Zähler: Ka₁·[H⁺] = 2,40×10⁻⁶ × 5,62×10⁻¹⁰ = 1,35×10⁻¹⁵
Nenner: (5,62×10⁻¹⁰)² + 2,40×10⁻⁶·5,62×10⁻¹⁰ + 2,04×10⁻¹⁵
       = 3,16×10⁻¹⁹ + 1,35×10⁻¹⁵ + 2,04×10⁻¹⁵ = 3,39×10⁻¹⁵
f(pH=9,25) = 1,35×10⁻¹⁵ / 3,39×10⁻¹⁵ = 0,398
3 Faktor der Abnahme:
v(pH=7) / v(pH=9,25) = f(7) / f(9,25) = 0,952 / 0,398 = 2,39
Die Reaktionsrate sinkt bei pH = 9,25 um den Faktor ≈ 2,4 gegenüber dem neutralen pH-Wert.

Bei pH 9,25 liegt Urease zu ~60% als U²⁻ (überdeprotoniert, inaktiv) vor – daher die deutliche Aktivitätsabnahme.

Aufgabe 5: Phasenporträts – Zuordnung

Phasenporträts zeigen pH als Funktion der Produktkonzentration. Drei Szenarien:

Diagramm (a)
pH steigt monoton mit den Produkten, flacht dann ab – einfache, geschwungene Kurve
→ Szenario (2)
Urease ohne Puffer: NH₃ erhöht pH → Urease verlangsamt sich → pH-Anstieg flacht ab bis fast Stillstand
Diagramm (b)
Hysterese-Schleife / Zyklisches Verhalten
→ Szenario (3)
Liposom: pH steigt innen → Urease inaktiviert → Produkte diffundieren raus → pH sinkt → neue Aktivität → Zyklen
Diagramm (c)
pH bleibt konstant, Produkte nehmen linear zu – gerade horizontale Linie
→ Szenario (1)
Pufferlösung: Puffer hält pH konstant → Urease arbeitet mit konstanter Rate → linearer Produktanstieg
(1) Pufferlösung → (c) (gerade Linie: pH = const)
(2) Neutral ohne Puffer → (a) (einfache Kurve: pH steigt, dann Plateau)
(3) Liposomen → (b) (Hysterese/Zyklen durch Membrandiffusion)

Aufgabe 6: Mindestkonzentration Ca²⁺ für CaCO₃-Fällung

Aus Aufgabe 4a: pH = 9,25, [HCO₃⁻] = 0,005 M. Gesucht: [CO₃²⁻] → daraus [Ca²⁺]min.

1 [CO₃²⁻] aus dem Gleichgewicht HCO₃⁻ ⇌ H⁺ + CO₃²⁻:
Ka₂(HCO₃⁻) = [H⁺]·[CO₃²⁻] / [HCO₃⁻] = 10⁻¹⁰·³³ = 4,68×10⁻¹¹

[CO₃²⁻] = Ka₂·[HCO₃⁻] / [H⁺]
         = 4,68×10⁻¹¹ × 0,005 / 10⁻⁹·²⁵
         = 4,68×10⁻¹¹ × 0,005 / 5,62×10⁻¹⁰
         = 4,16×10⁻⁴ M
2 Löslichkeitsprodukt:
Ksp(CaCO₃) = [Ca²⁺]·[CO₃²⁻] = 3,36×10⁻⁹
[Ca²⁺]min = Ksp / [CO₃²⁻] = 3,36×10⁻⁹ / 4,16×10⁻⁴ = 8,08×10⁻⁶ M
[Ca²⁺]min = 8,1×10⁻⁶ M = 8,1 μM

Schon bei sehr kleinen Ca²⁺-Konzentrationen beginnt CaCO₃ auszufallen – das erklärt die Fähigkeit der Urease, Kalk (CaCO₃) in Mauerrissen zu fällen und diese so zu versiegeln!

Aufgabe 7: Michaelis-Menten mit kompetitivem Inhibitor B(OH)₃

B(OH)₃ ist ein kompetitiver Inhibitor: Er bindet reversibel an HU⁻ und blockiert damit die Substratbindung. Der Komplex [Urease·B(OH)₃] hat dieselben pKₐ-Werte wie freie Urease.

Erweiterter Gleichgewichtsansatz:

Urease-Spezies (frei): H₂U, HU⁻, U²⁻
Inhibitor-Komplex-Spezies: H₂(U·I), H(U·I)⁻, (U·I)²⁻

Da der Komplex dieselben pKₐ-Werte hat wie freie Urease, gilt analog:
[H(U·I)⁻] = [HU⁻]·[I]/KI
[H₂(U·I)] = [H(U·I)⁻]·[H⁺]/Ka₁ = [HU⁻]·[I]·[H⁺]/(KI·Ka₁)
[(U·I)²⁻] = Ka₂·[H(U·I)⁻]/[H⁺] = Ka₂·[HU⁻]·[I]/(KI·[H⁺])
Der pH-abhängige Block des Inhibitor-Komplexes ist identisch zu dem der freien Urease, multipliziert mit [I]/KI.
Gesamtkonzentration:
[U]total = (Freie Urease-Formen) + (Inhibitor-Komplex-Formen)
= [HU⁻]·DpH/(Ka₁·[H⁺]) + [HU⁻]·DpH/(Ka₁·[H⁺]) · [I]/KI
= [HU⁻]·DpH/(Ka₁·[H⁺]) · (1 + [I]/KI)
wobei DpH = [H⁺]² + Ka₁·[H⁺] + Ka₁·Ka₂
[HU⁻] = Ka₁·[H⁺]·[U]total / { DpH · (1 + [I]/KI) }
Kompetitive Hemmung: Km wird zu Kmeff = Km·(1 + [I]/KI):
v = k₂·[HU⁻]·[S] / (Km·(1+[I]/KI) + [S])
Endformel mit Inhibitor (Aufgabe 7):
v = k₂·Ka₁·[H⁺]·[U]total·[S]total / { DpH·(1+[I]/KI)·(Km·(1+[I]/KI)+[S]total) }
DpH = [H⁺]² + Ka₁·[H⁺] + Ka₁·Ka₂  |  [I] = [B(OH)₃]total

Aufgabe 8: KI aus dem Steigungsverhältnis des Lineweaver-Burk-Plots

Der Lineweaver-Burk-Plot (1/v gegen 1/[S]) ist linear. Die Steigung ergibt sich durch Umformen:

1 Reziproke der Ratengleichung:
1/v = DpH·(1+[I]/KI)·Km·(1+[I]/KI) / (k₂·Ka₁·[H⁺]·[U]total) · 1/[S]total + const
Steigung m ∝ (1+[I]/KI)²
2 Verhältnis der Steigungen bei zwei Inhibitorkonzentrationen ([U]total, pH, T gleich):
m([I]₁) / m([I]₂) = (1+[I]₁/KI)² / (1+[I]₂/KI)² = 2,48
mit [I]₁ = 0,300 mM, [I]₂ = 0,075 mM
3 Quadratwurzel ziehen:
(1+[I]₁/KI) / (1+[I]₂/KI) = √2,48 = 1,5748
1 + 0,300/KI = 1,5748 · (1 + 0,075/KI)
1 + 0,300/KI = 1,5748 + 1,5748·0,075/KI
0,300/KI − 0,1181/KI = 1,5748 − 1
0,1819/KI = 0,5748
KI = 0,1819 / 0,5748 = 0,3164 mM = 3,16×10⁻⁴ M
4 Probe:
((1+0,300/0,316)/(1+0,075/0,316))² = (1,948/1,237)² = (1,575)² = 2,48 ✓
KI = 0,316 mM = 3,16×10⁻⁴ M bei 25°C

Aufgabe 9: ΔrH° und ΔrS° der Borsäure-Bindung

Gegeben: KI(25°C) = 3,16×10⁻⁴ M (aus Aufgabe 8), KI(35°C) = 1,57×10⁻⁴ M.

Beachte: KI sinkt mit steigender Temperatur → die Bindung wird bei höherer T stärker → endotherme Bindung, aber entropisch begünstigt (hydrophober Effekt).

Konvention: Wir berechnen ΔrH° und ΔrS° für die Bindungsreaktion:
Urease + B(OH)₃ → [Urease·B(OH)₃]  (Kbind = 1/KI)
1 ΔrH° via Van't-Hoff-Gleichung:
ln(KI₂/KI₁) = −ΔrH°diss/R · (1/T₂ − 1/T₁)
ln(1,57×10⁻⁴ / 3,16×10⁻⁴) = ln(0,4968) = −0,7009
1/T₂ − 1/T₁ = 1/308,15 − 1/298,15 = −1,088×10⁻⁴ K⁻¹

ΔrH°diss = −R · (−0,7009) / (−1,088×10⁻⁴)
               = −8,314 × (−0,7009) / (−1,088×10⁻⁴)
               = −53 540 J/mol
ΔrH°(Bindung) = −ΔrH°(Dissoziation) = +53,5 kJ/mol
2 ΔrG° der Bindung bei 25°C (Kbind = 1/KI = 3162 M⁻¹):
ΔrG°(Bindung) = −RT·ln(Kbind) = −8,314·298,15·ln(3162) = −19 975 J/mol = −20,0 kJ/mol
3 ΔrS° der Bindung:
ΔrS° = (ΔrH° − ΔrG°)/T = (53 540 − (−19 975)) / 298,15 = 73 515 / 298,15 = +246,6 J·mol⁻¹·K⁻¹

Physikalische Interpretation:
ΔrH° > 0 (endotherm): Die direkte Bindungsenthalpie ist ungünstig – das Aufbrechen von Hydrathüllen und die Konformationsänderung kosten Energie.
ΔrS° ≫ 0 (stark positiv): Der hydrophobe Effekt freigesetzter Wassermoleküle treibt die Bindung entropisch an.
→ ΔrG° = ΔrH° − T·ΔrS° = 53 500 − 298×246,6 = −20 000 J/mol: spontan, weil T·ΔrS° >> ΔrH°.
