📚 Grundwissen: Was sind Nanozyme?

Nanozyme sind Nanopartikel, die enzymatische Aktivität zeigen – sie beschleunigen chemische Reaktionen wie natürliche Enzyme, sind aber stabiler, günstiger und in ihrer Aktivität einstellbar. In dieser Aufgabe untersuchen wir:

  • Ein Eisenoxid-Nanozym (XnOm) mit Peroxidase-Aktivität: Oxidiert Substrate mit H₂O₂ via Fenton-Reaktion
  • Ein C₆₀-Fullerene-Nanozym mit vielseitiger Enzymaktivität

Die Michaelis-Menten-Kinetik beschreibt, wie schnell ein Enzym (oder Nanozym) ein Substrat umsetzt:

r = rmax · [S] / (KM + [S])
  • r = momentane Reaktionsgeschwindigkeit
  • rmax = maximale Geschwindigkeit (alle Bindungsstellen besetzt)
  • KM = Michaelis-Konstante ([S] bei der r = rmax/2)

Aufgabe 1: Element X und Salze S1, S2 bestimmen

Schritt 1: Element X aus der Massenspektrometrie von S1

Das ESI-MS von S1 zeigt zwei intensive Peaks:

  • Positives Ion [XHal₂(H₂O)₄]⁺ mit m/z = 198
  • Negatives Ion [XHal₄]⁻ mit m/z = 196
1 Gleichungssystem aufstellen:
(I) M(X) + 4·M(Hal) = 196 → aus [XHal₄]⁻
(II) M(X) + 2·M(Hal) + 4·M(H₂O) = 198 → aus [XHal₂(H₂O)₄]⁺
M(X) + 2·M(Hal) + 4·18 = 198
M(X) + 2·M(Hal) = 126
2 Subtrahieren (I) − (II):
2·M(Hal) = 196 − 126 = 70 → M(Hal) = 35 → Hal = Cl (M = 35,45)
3 M(X) berechnen:
M(X) = 126 − 2·35 = 56 → X = Fe (Eisen, M = 55,85 g/mol)
4 Überprüfung:
[FeCl₂(H₂O)₄]⁺: 55,85 + 2·35,45 + 4·18,02 = 198,82 ≈ 198 ✓
[FeCl₄]⁻: 55,85 + 4·35,45 = 197,65 ≈ 196 ✓

Schritt 2: Salz S1 bestimmen

Das positive Ion [FeCl₂(H₂O)₄]⁺ ist charakteristisch für Fe³⁺ in Lösung (verliert im ESI-Prozess ein Cl⁻ und koordiniert 4 Wassermoleküle). Das negative Ion [FeCl₄]⁻ entsteht durch Anlagerung von Cl⁻ an FeCl₃.

Beide Ionen stammen aus FeCl₃ (Eisen(III)-chlorid). In wässriger Lösung / ESI:
FeCl₃ → [FeCl₂(H₂O)₄]⁺ (Kation) und [FeCl₄]⁻ (Anion, durch Cl⁻-Anlagerung)

Überprüfung mit der Einwaage 2,7025 g S1 = FeCl₃·6H₂O:

M(FeCl₃·6H₂O) = 55,85 + 3·35,45 + 6·18,02 = 270,29 g/mol
n(FeCl₃·6H₂O) = 2,7025 / 270,29 = 0,01000 mol Fe³⁺

Schritt 3: Salz S2 bestimmen

Gegebene Eigenschaften: grün → weiß oberhalb 300°C, Massenverlust 45,36%, Massenanteil Fe = 20,09%.

1 Molare Masse berechnen:
M(S2) = M(Fe) / w(Fe) = 55,85 / 0,2009 = 277,97 g/mol
2 Wasseranteil:
Masse H₂O = 0,4536 · 277,97 = 126,10 g/mol → n(H₂O) = 126,10 / 18,02 = 7
3 Restliche Masse:
M(S2 ohne H₂O) = 277,97 − 7·18,02 = 151,85 ≈ M(FeSO₄) = 151,91 g/mol ✓
4 Vollständige Überprüfung FeSO₄·7H₂O:
M(FeSO₄·7H₂O) = 55,85 + 32,06 + 4·16,00 + 7·18,02 = 278,01 g/mol
w(Fe) = 55,85 / 278,01 = 20,09% ✓ (gegeben: 20,09%)
Verlust 7H₂O = 7·18,02 / 278,01 = 45,36% ✓ (gegeben: 45,36%)
Farbe FeSO₄·7H₂O: grün; wasserfreies FeSO₄: weiß ✓

Einwaage: n(FeSO₄·7H₂O) = 1,3901 / 278,01 = 0,00500 mol Fe²⁺

X = Fe (Eisen)
S1 = FeCl₃·6H₂O (Eisen(III)-chlorid-Hexahydrat) → liefert Fe³⁺
S2 = FeSO₄·7H₂O (Eisen(II)-sulfat-Heptahydrat, Vitriol) → liefert Fe²⁺

Aufgabe 2: n und m in XnOm bestimmen

Molenverhältnis Fe³⁺ : Fe²⁺

n(Fe³⁺) = 2,7025 g / 270,29 g·mol⁻¹ = 0,01000 mol
n(Fe²⁺) = 1,3901 g / 278,01 g·mol⁻¹ = 0,00500 mol
Verhältnis Fe³⁺ : Fe²⁺ = 0,01000 : 0,00500 = 2 : 1
Das Verhältnis 2 Fe³⁺ : 1 Fe²⁺ entspricht genau der Zusammensetzung von Fe₃O₄ (Magnetit):
Fe₃O₄ = FeO · Fe₂O₃ = 1 Fe²⁺ + 2 Fe³⁺ pro Formeleinheit

Massenüberprüfung

n(Fe gesamt) = 0,01000 + 0,00500 = 0,01500 mol
n(Fe₃O₄) = 0,01500 / 3 = 0,00500 mol
M(Fe₃O₄) = 3·55,85 + 4·16,00 = 231,55 g/mol
m(Fe₃O₄) = 0,00500 · 231,55 = 1,1575 g ≈ 1,1578 g ✓ (gegeben)
XnOm = Fe₃O₄ (Magnetit)
n = 3, m = 4
Dies ist das bekannte Eisenmineral Magnetit, ein gemischtes Eisen(II/III)-oxid.

Aufgabe 3: Ionische Reaktionsgleichung der Co-Fällung

Bei der Co-Fällung werden Fe²⁺ und Fe³⁺ durch Tetramethylammoniumhydroxid (TMAOH) als Base gefällt. Die Hydroxid-Ionen deprotonieren und bilden mit den Eisen-Ionen das Oxid.

Herleitung der Gleichung:

1 Edukte: 1 Fe²⁺ + 2 Fe³⁺ + ? OH⁻ → Fe₃O₄ + ? H₂O
2 Sauerstoffbilanz: Fe₃O₄ hat 4 O-Atome → kommen alle aus OH⁻ → 8 OH⁻ nötig (da 8 OH → 4 O in Oxid + 4 O in H₂O)
3 Wasserstoffbilanz: 8 OH⁻ → 4 H₂O ✓
4 Ladungsbilanz: (+2) + 2·(+3) + 8·(−1) = 2 + 6 − 8 = 0 ✓
Fe²⁺ + 2 Fe³⁺ + 8 OH⁻ → Fe₃O₄↓ + 4 H₂O
Warum funktioniert diese Reaktion?
Fe₃O₄ ist extrem schwerlöslich (Ksp ≈ 10⁻⁴⁰). In alkalischer Lösung (hoher OH⁻-Überschuss) werden die Fe-Ionen vollständig ausgefällt. Die gleichzeitige Fällung von Fe²⁺ und Fe³⁺ im Verhältnis 1:2 ergibt direkt die gewünschte Magnetit-Stöchiometrie.

Aufgabe 4: Welches Oxid entsteht nach dem Aktivitätsverlust?

Die Peroxidase-Reaktion (Fenton-ähnlich):

Fe²⁺ + H₂O₂ → Fe³⁺ + OH• + OH⁻

In dieser Reaktion wird Fe²⁺ zu Fe³⁺ oxidiert. Damit funktioniert der Katalyse-Zyklus: das Fe³⁺ muss wieder zu Fe²⁺ reduziert werden.

Problem: In wässriger Lösung mit Luftsauerstoff und überschüssigem H₂O₂ kann Fe²⁺ nicht effizient regeneriert werden. Mit der Zeit wird das gesamte Fe²⁺ im Fe₃O₄ zu Fe³⁺ oxidiert → es entsteht ein reines Fe³⁺-Oxid.

Massenanteil-Vergleich der Eisenoxide:

VerbindungFormelM [g/mol]w(Fe)
MagnetitFe₃O₄231,553·55,85/231,55 = 72,36%
HämatitFe₂O₃159,692·55,85/159,69 = 69,94%
WüstitFeO71,8555,85/71,85 = 77,73%

Gesucht: w(Fe) kleiner als in Fe₃O₄ (72,36%) → nur Fe₂O₃ (69,94%) erfüllt das.

Chemische Begründung: Fe₃O₄ enthält Fe²⁺ und Fe³⁺. Durch vollständige Oxidation von Fe²⁺ zu Fe³⁺ entsteht:
4 Fe₃O₄ + O₂ → 6 Fe₂O₃
Fe₂O₃ enthält nur Fe³⁺. Da die Peroxidase-Reaktion Fe²⁺ als Reduktionsmittel benötigt, ist Fe₂O₃ katalytisch inaktiv.
Das nach dem Aktivitätsverlust entstehende Oxid ist Fe₂O₃ (Hämatit).
w(Fe) = 69,94% < 72,36% (Fe₃O₄) ✓

Aufgabe 5: Welche Reagenzien erhalten die katalytische Aktivität?

Das Problem: Fe²⁺ wird in der Fenton-Reaktion zu Fe³⁺ oxidiert und nicht regeneriert. Um die katalytische Aktivität zu erhalten, brauchen wir ein Reagenz, das Fe³⁺ wieder zu Fe²⁺ reduziert.

Analyse der Optionen:

a) NaIO₄ (Natriumperiodat):
IO₄⁻ ist ein starkes OXIDATIONSMITTEL. Es würde Fe²⁺ weiter zu Fe³⁺ oxidieren – das Gegenteil von dem, was wir brauchen.
✗ NEIN
b) NaBH₄ (Natriumborhydrid):
BH₄⁻ ist ein starkes REDUKTIONSMITTEL. Es kann Fe³⁺ zu Fe²⁺ reduzieren:
Fe³⁺ + e⁻ → Fe²⁺
Damit wird das verbrauchte Fe²⁺ regeneriert. Allerdings ist NaBH₄ sehr stark und könnte bei Überschuss Fe vollständig zu Fe⁰ reduzieren.
✓ JA (mit Vorsicht)
c) Na₃C₆H₅O₇ (Natriumcitrat):
Citrat wirkt als mildes REDUKTIONSMITTEL und Komplexbildner. Es kann:
① Fe³⁺ schonend zu Fe²⁺ reduzieren
② Als Ligand die Fe-Ionen an der Oberfläche der NPs stabilisieren
③ Agglomeration der Nanopartikel verhindern
✓ JA (ideal – mild und selektiv)
d) Na₃PO₄ (Natriumphosphat):
Phosphat hat keine Redoxaktivität gegenüber Eisen. Es ist eine Base und wirkt als Fällungsmittel für Fe-Ionen (Fe-Phosphate sind schwerlöslich). Kann die NPs sogar zerstören.
✗ NEIN
Richtige Antworten: b) NaBH₄ und c) Na₃C₆H₅O₇ (Natriumcitrat)

Beide sind Reduktionsmittel, die Fe³⁺ → Fe²⁺ regenerieren und damit den Fenton-Zyklus aufrechterhalten. Citrat ist selektiver und milder – daher in der Praxis bevorzugt.

Aufgabe 6: Element Y und Zahl p bestimmen

Gegeben: Yp hat eine kovalente sphärische Struktur mit:

  • Volumen: V = 1,128 × 10⁻⁴ m³·mol⁻¹
  • Oberfläche: A = 1,324 × 10⁶ m²·kg⁻¹
Idee: Wenn Yp eine Kugel ist, können wir aus dem molaren Volumen den Radius berechnen. Aus der spezifischen Oberfläche erhalten wir die molare Masse. Das ergibt zusammen die Identität des Moleküls.

Schritt 1: Radius aus dem molaren Volumen

Das molare Volumen ist das Volumen einer Kugel mal NA:
Vmol = (4/3)·π·r³ · NA
Umformen nach r:
r = ∛(3·Vmol / (4·π·NA))
r = ∛(3 × 1,128×10⁻⁴ / (4 × π × 6,022×10²³))
r = ∛(3,386×10⁻⁴ / 7,560×10²⁴)
r = ∛(4,479×10⁻²⁹ m³)
r = 3,549 × 10⁻¹⁰ m = 0,355 nm = 3,55 Å

Schritt 2: Molare Masse aus der spezifischen Oberfläche

Die spezifische Oberfläche = Oberfläche pro kg Substanz:
Aspez = (4·π·r²·NA) / M
Umformen nach M:
M = (4·π·r²·NA) / Aspez
M = (4 × π × (3,549×10⁻¹⁰)² × 6,022×10²³) / 1,324×10⁶
M = (4 × π × 1,260×10⁻¹⁹ × 6,022×10²³) / 1,324×10⁶
M = 9,523×10⁵ / 1,324×10⁶
M = 0,7192 kg/mol = 719,2 g/mol

Schritt 3: Identifikation

Welches kovalent-sphärische Molekül hat M ≈ 720 g/mol?

Buckminsterfullerene C₆₀!
M(C₆₀) = 60 × 12,011 = 720,66 g/mol ≈ 720 g/mol ✓

C₆₀ ist ein fußballförmiges Molekül aus 60 Kohlenstoffatomen, die 20 Hexagone und 12 Pentagone bilden. Sein Radius beträgt ~3,5 Å (Kohlenstoffgerüst) ✓

Es ist das bekannteste Fullerene und wurde 1996 mit dem Nobelpreis für Chemie ausgezeichnet (Curl, Kroto, Smalley).
Y = C (Kohlenstoff), p = 60
Yp = C₆₀ (Buckminsterfullerene / „Buckyball")
Radius: 3,55 Å ✓  |  Molare Masse: 720,1 g/mol ≈ 720,7 g/mol ✓

Aufgabe 7: Substratkonzentration bei gegebener Reaktionsrate

Gegeben: KM = 1,03 mM = 1,03 × 10⁻³ mol/L, rmax = 3,73 nM/s = 3,73 × 10⁻⁹ mol/L/s

Aufgabe: r = 0,001 µM/min → [S] = ?

Schritt 1: Einheitenumrechnung

r = 0,001 µM/min = 0,001 × 10⁻⁶ mol/L / 60 s = 1,667 × 10⁻¹¹ mol/L/s

Schritt 2: Michaelis-Menten nach [S] umformen

r = rmax · [S] / (KM + [S])
Multipliziere beide Seiten mit (KM + [S]):
r · KM + r · [S] = rmax · [S]
Terme mit [S] auf eine Seite:
r · KM = (rmax − r) · [S]
[S] = r · KM / (rmax − r)

Schritt 3: Einsetzen

[S] = (1,667×10⁻¹¹ × 1,03×10⁻³) / (3,73×10⁻⁹ − 1,667×10⁻¹¹)
[S] = 1,717×10⁻¹⁴ / 3,713×10⁻⁹
[S] = 4,623 × 10⁻⁶ mol/L = 4,62 µM
Warum geht die Näherung rmax − r ≈ rmax auch?
r = 1,667×10⁻¹¹ ist 224-mal kleiner als rmax = 3,73×10⁻⁹ → r ≪ rmax → Näherung sehr gut:
[S] ≈ r·KM/rmax = 1,667×10⁻¹¹ × 1,03×10⁻³ / 3,73×10⁻⁹ = 4,60 µM (≈ 4,62 µM ✓)
[S] ≈ 4,62 µM
Die Rate 0,001 µM/min entspricht einer sehr niedrigen Substratkonzentration von 4,62 µM – weit unter KM = 1030 µM. Das Nanozym arbeitet also im linearen (substrat-limitierten) Bereich.

Aufgabe 8: Zeit zur Bildung von 0,025 µM Produkt

Gegeben: [S]₀ = 0,025 mM = 2,5 × 10⁻⁵ mol/L, Ziel: [P] = 0,025 µM = 2,5 × 10⁻⁸ mol/L

Schritt 1: Ist [S] ≫ KM oder [S] ≪ KM?

[S]₀ / KM = 0,025 mM / 1,03 mM = 0,0243

→ [S]₀ ≪ KM! Das Substrat ist im Verhältnis zur Michaelis-Konstante sehr gering.

Schritt 2: Wird [S] während der Reaktion signifikant verbraucht?

Umgesetzter Anteil = [P]Ziel / [S]₀ = 0,025 µM / 25 µM = 0,1%
Nur 0,1% des Substrats werden verbraucht! Daher bleibt [S] ≈ [S]₀ während der gesamten Reaktion. Die Rate ist praktisch konstant – wir können einfach t = [P] / r berechnen.

Schritt 3: Reaktionsrate bei [S]₀ berechnen

r = rmax · [S]₀ / (KM + [S]₀)
r = 3,73×10⁻⁹ × 2,5×10⁻⁵ / (1,03×10⁻³ + 2,5×10⁻⁵)
r = 9,325×10⁻¹⁴ / 1,055×10⁻³
r = 8,839 × 10⁻¹¹ mol/L/s
Vereinfachung (da [S]₀ ≪ KM): r ≈ rmax·[S]₀/KM = 3,73×10⁻⁹ × 2,5×10⁻⁵ / 1,03×10⁻³ = 9,05×10⁻¹¹ mol/L/s (sehr nah am exakten Wert ✓)

Schritt 4: Zeit berechnen

t = [P]Ziel / r
t = 2,5×10⁻⁸ mol/L / 8,839×10⁻¹¹ mol/L/s
t = 282,8 s = 4,71 min
t ≈ 4,71 Minuten

In knapp 5 Minuten produziert das C₆₀-Nanozym 0,025 µM Produkt aus einer 0,025 mM Substratlösung. Die Rechnung war einfach, weil:
① Der Umsatz extrem gering ist (0,1%) → konstante Rate
② [S] ≪ KM → erste Ordnung in [S] (Linearität)
