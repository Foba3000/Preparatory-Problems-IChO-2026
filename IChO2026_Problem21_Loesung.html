🔴 Problem 21 – Katalysator C: Wilkinson-Katalysator
Vollständige Lösung – RhCl(PPh₃)₃, Massenspektrometrie & [2+2+2]-Cycloaddition

📚 Grundwissen: Wilkinson-Katalysator

RhCl(PPh₃)₃ (Wilkinson-Katalysator, C) ist einer der wichtigsten homogenen Katalysatoren in der organischen Chemie. Er katalysiert die Hydrierung von Alkenen unter milden Bedingungen (Raumtemperatur, 1 atm H₂). Der Mechanismus verläuft über oxidative Addition von H₂ an Rh(I) → Rh(III), Koordination des Alkens, Insertion und reduktive Eliminierung.

Aufgabe 1: Identifikation von A, B, C und M

Schritt 1: Ligand B identifizieren

1 Bedingungen für B: Enthält nur C, H, P · w(P) = 11,81 % · dreizählige Symmetrieachse (C₃)
2 Dreizählige Symmetrie + P + C + H:
→ PPh₃ (Triphenylphosphin)! Die 3 Phenylringe erzeugen die C₃-Achse.
M(PPh₃) = M(P) + 3 × M(C₆H₅) = 30,974 + 3 × (72,066 + 5,040)
= 30,974 + 3 × 77,106 = 30,974 + 231,318 = 262,29 g/mol

w(P) = 30,974 / 262,29 = 11,81% ✓
B = PPh₃ (Triphenylphosphin): C₁₈H₁₅P, M = 262,29 g/mol

Schritt 2: Metall M und Verbindung A

3 Bekannter PPh₃-Katalysator für Alken-Hydrierung: Wilkinson-Katalysator RhCl(PPh₃)₃!
→ M = Rh (Rhodium), 5. Periode ✓ (Z=45, M=102,906 g/mol)

A ist das Rh-Trihydrat-Salz: RhCl₃·3H₂O
w(Rh in RhCl₃·3H₂O) = 102,906 / (102,906 + 3×35,453 + 3×18,015) = 102,906 / 263,31 = 39,08% ≈ 39,09% ✓

Schritt 3: Stöchiometrie bestätigen

4 Aus den eingesetzten Mengen:
n(A) = 2,00 g / 263,31 g·mol⁻¹ = 0,00760 mol
n(B) = 7,96 g / 262,29 g·mol⁻¹ = 0,03035 mol
n(B)/n(A) = 0,03035/0,00760 = 4,00 → 4 mol PPh₃ pro mol RhCl₃!
5 Ausbeute-Überprüfung:
M(C = RhCl(PPh₃)₃) = 102,906 + 35,453 + 3×262,29 = 925,24 g/mol
m(C) theoretisch = 0,00760 mol × 925,24 g/mol = 7,03 g
m(C) bei 88% = 7,03 × 0,88 = 6,18 g ✓ (gemessen!)
A = RhCl₃·3H₂O  |  B = PPh₃  |  C = RhCl(PPh₃)₃  |  M = Rh

Aufgabe 2: Synthesegleichung von C

Reaktion: RhCl₃·3H₂O + 4 PPh₃ → RhCl(PPh₃)₃ + OPPh₃ + 2 HCl + 3 H₂O
Mechanismus erklärt:
• Rh(III) wird zu Rh(I) reduziert (Oxidationszustandsänderung +3 → +1)
• Ein PPh₃ fungiert als Reduktionsmittel und wird dabei zu OPPh₃ (Triphenylphosphinoxid) oxidiert
• Die restlichen 3 PPh₃ koordinieren als Liganden am Rh(I)
• 2 HCl und 3 H₂O werden als Nebenprodukte freigesetzt
RhCl₃·3H₂O + 4 PPh₃ → RhCl(PPh₃)₃ + OPPh₃ + 2 HCl + 3 H₂O
Koeffizienten: 1, 4, 1, 1, 2, 3 → alle < 5 ✓
Bilanz: Rh(III)→Rh(I) (Reduktion) · 1 PPh₃→OPPh₃ (Oxidation) · Redoxreaktion intern!

Aufgabe 6: Nebenprodukt D

Das Schema zeigt: R–CH=CH₂ → D (ohne H₂, nur mit Cat. C).
Das bedeutet: Wilkinson-Katalysator katalysiert eine Isomerisierung (nicht Hydrierung)!

Alken-Isomerisierung durch Rh-Katalysator:
R–CH=CH₂ (terminales Alken) → R–CH₂–CH=... (internes Alken)
Der Rh-Komplex insertiert in die C–H-Bindung und verschiebt die Doppelbindung.
Wenn das Edukt = Allyl-Aryl-Verbindung (z.B. Ph–CH₂–CH=CH₂):
Ph–CH₂–CH=CH₂  →(Cat. C, keine H₂)→  Ph–CH=CH–CH₃

D = Ph–CH=CH–CH₃ (1-Phenylpropen, internes Alken)
= Allylbenzol → β-Methylstyrol (Isomerisierung der Doppelbindung)
D = internes Alken (isomerisiertes Edukt), z.B. Ph–CH=CH–CH₃
Mechanismus: Rh-katalysierte 1,3-H-Verschiebung (Alken-Isomerisierung)

Aufgabe 7: Zersetzung von C – Verbindung F und Oxidationsreaktion

Nach mehreren katalytischen Zyklen zerfällt C in M (= Rh, metallisches Rhodium) und F.
F entsteht durch Oxidation von B (= PPh₃) mit Luftsauerstoff O₂.
Reaktion:
PPh₃ reagiert sehr leicht mit O₂ (Luftsauerstoff):
2 PPh₃ + O₂ → 2 OPPh₃
oder:   PPh₃ + ½ O₂ → OPPh₃
Produkt F = OPPh₃ (Triphenylphosphinoxid)
Struktur: Ph₃P=O (P in +5 Oxidationsstufe, O doppelt gebunden)
M(OPPh₃) = 262,29 + 16,00 = 278,29 g/mol

OPPh₃ ist ein stabiles Nebenprodukt und ein schlechter Ligand (koordiniert kaum an Rh)
→ der Katalysator verliert seinen Liganden und zerfällt!
F = OPPh₃ (Triphenylphosphinoxid)
Oxidationsreaktion: 2 PPh₃ + O₂ → 2 OPPh₃
Gesamtzerfall: RhCl(PPh₃)₃ → Rh(0) + RhClₓ + OPPh₃ + ... (katalytische Desaktivierung)

Aufgabe 8: [2+2+2]-Cycloaddition in der Heilonine-Synthese – Strukturen H, I, J

[2+2+2]-Cycloaddition: Drei π-Systeme (2+2+2 Elektronen) reagieren zu einem 6-gliedrigen Ring. Bei 2 Alkinen + 1 Alkin/Alken entsteht ein Benzol- oder Cyclohexadien-Ring. Der Wilkinson-Katalysator C aktiviert die Alkine durch Koordination an Rh.

Verbindung H

Edukte: (a) Lactam mit Diyin-Seitenkette (NH-Lactam + 2 C≡C) + (b) Bromid mit Diyin-Kette + Acetal
Reagenz: NaH (starke Base, deprotoniert NH des Lactams → N⁻ Anion)
Reaktion: N-Alkylierung: Das Lactam-N⁻ greift den Alkylbromid an (SN2) → N–C-Bindung wird geknüpft

H = N-alkyliertes Lactam-Diyin: Das Lactam-Fragment mit dem Brombaustein verbunden.
Enthält: Lactam-Ring (C=O, NH→N-R), zwei endständige Alkin-Gruppen, Acetal-Schutzgruppe (1,3-Dioxolan).

Verbindung I

Reagenz: Cat. C (Wilkinson-Katalysator, [2+2+2]-Cycloaddition)
Reaktion: Die zwei Alkin-Gruppen in H reagieren intramolekular mit dem dritten π-System (weitere Alkin-Einheit oder Alken) in einer [2+2+2]-Cycloaddition:
  • Rh(I) koordiniert an die zwei Alkine → Rhodacyclopentadien-Intermediat
  • Das dritte π-System insertiert → 6-gliedriger Ring entsteht
  • Nach reduktiver Eliminierung: Benzolring entsteht!
I = Polycyclisches Produkt mit neuem Benzolring (aus den zwei Alkin-Einheiten). Das Steroidal-Grundgerüst (aus dem Diyin-Baustein) ist jetzt mit dem Lactam-Fragment über den neuen aromatischen Ring verbunden. Das Acetal bleibt intakt.

Verbindung J

Schritt: I + (1) LiTMP (2) MeI
Reaktion:
  1. LiTMP (Lithium-2,2,6,6-tetramethylpiperidid): sehr starke, sterisch gehinderte Base. Deprotoniert α zur Carbonyl-Gruppe des Lactams → Enolat-Anion
  2. MeI (Methyliodid): Alkyliert das Enolat → Methyl-Gruppe wird α zum Carbonyl eingeführt
J = α-methyliertes Derivat von I. Die Methyl-Gruppe ist an der α-Position zum Lactam-C=O eingeführt worden. Die Acetal-Schutzgruppe bleibt noch erhalten.
Folgeschritte (Heilonine):
J + p-TsOH, H₂O, Aceton → Acetal-Hydrolyse → Keton freigesetzt → Lactamöffnung und weitere Schritte → Heilonine

Heilonine ist ein pentacyclischer Naturstoff mit Steroidal-Grundgerüst und einem zentralen aromatischen Ring (aus der [2+2+2]-Cycloaddition), Lactam-Ring und einem Cyclohexandiol-Abschnitt.
H = N-alkyliertes Lactam-Diyin (NaH-Kupplung der beiden Bausteine)
I = Polycyclisches Aromat-enthaltentes Produkt (nach [2+2+2]-intramolekularer Cycloaddition → neuer Benzolring)
J = α-methyliertes Derivat von I (LiTMP-Deprotonierung + MeI-Alkylierung am Lactam)

Historische Bedeutung des Wilkinson-Katalysators:
RhCl(PPh₃)₃ wurde 1964 von Geoffrey Wilkinson entwickelt (Nobelpreis 1973 zusammen mit Ernst Otto Fischer für metallorganische Chemie). Es war der erste praktische homogene Katalysator für die selektive Alken-Hydrierung unter milden Bedingungen (1 atm H₂, Raumtemperatur) und revolutionierte die asymmetrische Synthese.
